Overview

Teknomen Length & Batch Controllers are dedicated production-monitoring devices that track produced length and completed batches, with preset alarms and automatic actions based on configured values.

Operators set the length and batch targets, which improves production monitoring and process control.

Features

Key features

01

Length counting

Tracks produced length in real time with high accuracy.

02

Preset values

Operators set target lengths and the controller acts when they are reached.

03

Automatic actions

Triggers relays, alarms or a machine stop when presets are met.

04

Batch counting

Counts completed batches and keeps a running total.

05

Preset alarms

Warns when length or batch targets are approaching or reached.

06

Dedicated device

Built only for length and batch accuracy, nothing else to configure.
